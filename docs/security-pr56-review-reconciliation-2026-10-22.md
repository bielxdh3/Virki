A null `credentialKeyVersion` is legitimate **only** during first credential setup, before a credential exists; other elevation scopes reject missing or invalid versions. The additive database migration must precede application rollout, and old pending ceremonies without a version must be restarted (not implicitly upgraded).

A token digest now selects a separate untrusted per-token bucket; the existing per-IP ceiling remains. HEAD `/me`, POST `/session/end/confirm`, and provider case/trailing-slash aliases are now covered by rate-limiting/canonicalization checks.

Interaction `SessionNotFound` remains 400; unknown storage/provider lookup exceptions return generic 503. A native interaction completion exception before headers now has an HTTP regression confirming bounded failure, issuer security headers and `no-store`.
- In `.github/workflows/ci.yml`, both `sudo node --test` steps have an explicit GitHub-hosted/Linux/exact-repository guard. The unprivileged and root-only fixtures remain separate; no hosted CI check is bypassed.
- A subsequent real disposable Docker/Node 22 audit found a critical Next.js 16.3.8 advisory in the previously locked tree (npm GHSA-2464-fhr4-w9xw, GHSA-p3m5-59mp-jv5r, GHSA-673q-mjm6-r5xr).
